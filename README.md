# JARA - Aplikasi Kelola Tugas

JARA adalah aplikasi web yang berbasis Laravel yang berguna untuk mengelola tugas pribadi maupun tugas dalam tim.

## Description

Aplikasi ini membantu pengguna:
- Membuat project/list tugas
- Membuat dan mengelola task
- Mengatur prioritas dan deadline
- Berkolaborasi dengan anggota tim
- Monitoring progress pekerjaan
